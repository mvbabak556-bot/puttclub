# آکادمی گلف پات کلاب | Putt Club Golf Academy

فقط پلن A. صفحه نخست، وب‌سایت رسمی آکادمی است (اهواز — puttclub.ir) و فروشگاه
تجهیزات در مسیر `/shop` قرار دارد. ساخته‌شده با Next.js، Drizzle و PostgreSQL.
بدون Service Worker و بدون PWA.

## لینک زنده

https://mvbabak556-bot.github.io/puttclub/

## بخش‌های عمومی

- `/` — خانه آکادمی (هیرو، درباره، دوره‌ها، فروشگاه، نظرات، تماس)
- `/shop` — فروشگاه تجهیزات
- `/product/[slug]` — صفحه محصول (گالری، دیدگاه، خرید)
- `/checkout` — تسویه ظاهری (درگاه واقعی ندارد)
- `/academy` — **نقطه وصل پنل مستقل** (پایین را ببینید)
- محتوای عمومی داخل پوشش پایدار `id="public-site"` است (در `src/components/SiteShell.tsx`)؛
  مسیرهای `/admin` بیرون این پوشش‌اند.

## نقطه وصل پنل مستقل (قرارداد)

پنل اعضای آکادمی یک پنل **مستقل و جدا** است که ایجنت دیگری می‌سازد.
این ریپو فقط «ورودی» آن را نگه می‌دارد و داخل آن پنل چیزی نمی‌سازد:

- `/academy` = نقطه وصل پنل مستقل. فایل: `src/app/academy/page.tsx`
- `#academy-root` = ظرف خالی وسط صفحه `/academy` که پنل مستقل به آن وصل می‌شود.
  اگر `NEXT_PUBLIC_ACADEMY_PANEL_URL` خالی باشد، این ظرف خالی می‌ماند.
- `#enter-members` = دکمه «ورود اعضای آکادمی»:
  - `id="enter-members"` فقط روی **اولین** لینک است: دکمه هدر در `src/components/Header.tsx`
  - بقیه لینک‌های هم‌نام (منوی موبایل هدر، هیرو، بخش آکادمی، بخش دوره‌ها، فوتر)
    `class="enter-members"` دارند و همه `href="/academy"` — بدون سخت‌کد دامنه یا سایت دیگر.
- در کل پروژه از این idها استفاده نشده و نخواهد شد:
  `app`، `login`، `l3d`، `view`، `l3d-enter`، `l3d-stage`، `l3d-panel`، `l3d-dock`
- صفحه `/academy` هیچ فرم ایمیل/رمز برای پنل مستقل ندارد.

### متغیر NEXT_PUBLIC_ACADEMY_PANEL_URL

- اگر خالی باشد: `#academy-root` خالی می‌ماند + یک خط کوتاه راهنما.
- اگر پر باشد (آدرس پنل مستقل): همان صفحه، پنل را داخل `iframe` در `#academy-root`
  نمایش می‌دهد.

## ورودها (سه ورود جدا — قاطی نکنید)

| ورود | مسیر | توضیح |
|---|---|---|
| اعضای فروشگاه | `/login` و `/panel` | خرید و پیگیری سفارش فروشگاه |
| مدیر سایت/فروشگاه | `/admin/login` | هر دو پنل `/admin` و `/admin/site` |
| اعضای آکادمی (پنل مستقل) | `/academy` | فقط ورودی؛ خود پنل بیرون این ریپو است |

## پنل‌های مدیریت (مال همین ریپو)

- `/admin` — **مدیریت فروشگاه**: نمای کلی، سفارش‌ها، محصولات، دسته‌بندی‌ها،
  دیدگاه‌های محصول، کاربران فروشگاه، پاپ‌آپ فروشگاه.
- `/admin/site` — **مدیریت سایت**: دوره‌های آموزشی (متن، عکس، حالت گالری،
  چیدمان، رنگ و اندازه، آیتم‌های پاورقی، شبکه‌های اجتماعی)، نظرات گلف‌بازان
  (تأیید/رد/حذف)، محتوا و تصاویر، قالب (CSS variableهای برند)، تماس، منو.
- حساب مدیر سایت/فروشگاه: نام کاربری `admin`
  (رمز فقط نزد مالک است و در ریپو نوشته نمی‌شود).
- این حساب هیچ ربطی به پنل مستقل آکادمی ندارد.

## پاپ‌آپ فروشگاه (به‌زودی)

- با باز شدن `/shop`، اگر در پنل فعال باشد، پاپ‌آپ «به‌زودی / حالت آزمایشی»
  نمایش داده می‌شود؛ فقط دکمه «برگشت به سایت» دارد و دکمه بستن ندارد.
- ورود مخفی فقط با تایپ رمز انگلیسی روی صفحه‌کلید انجام می‌شود (پیش‌فرض: `B`،
  بدون حساسیت به بزرگی/کوچکی؛ می‌تواند یک کلمه مثل `Babak` هم باشد).
- مدیریت از پنل فروشگاه (`/admin` ← تب «پاپ‌آپ فروشگاه»): روشن/خاموش، ویرایش
  تیتر و متن و دکمه، تغییر رمز. رمز هیچ‌وقت در API عمومی و اسنپ‌شات استاتیک
  قرار نمی‌گیرد و فقط سمت سرور بررسی می‌شود (`POST /api/site/shop-gate/unlock`).
